# v3.0.0

## Breaking Changes

**None** - This release maintains full backward compatibility with v2.x despite the major version bump.

## Library Updates

Updated all Serilog dependencies to their latest stable versions:

* **Serilog**: 2.12.0 → 4.3.0
* **Serilog.Sinks.Console**: 4.1.0 → 6.0.0
* **Serilog.Sinks.File**: 5.0.0 → 7.0.0
* **PowerShellStandard.Library**: 5.1.0 → 5.1.1

These updates bring significant improvements including:
- Enhanced performance and reliability
- Better structured logging capabilities
- Improved async logging support
- Latest security patches and bug fixes from the Serilog ecosystem

## Bugfixes

* **Fixed memory leak in PowerShellSink** - The `StringWriter` instance in the `Emit()` method is now properly disposed using a `using` statement, preventing memory leaks in long-running sessions.
* **Fixed null reference exceptions in Table rendering** - Added null-coalescing operators to safely handle null values when rendering multiline cell content in error record tables.
* **Fixed thread-safety issue in Cell class** - Removed static mutable `MaxWidth` field that could cause issues in concurrent logging scenarios.
* **Fixed empty list handling in Column class** - Added defensive check to prevent exceptions when calculating `MaxWidth` on empty cell collections.
* **Code cleanup** - Removed unnecessary empty constructors in `ErrorRecordEnricher` and `WrapperException` classes, consolidating to single constructors with default parameters.

## Documentation

* Updated copyright year to 2019-2025
* Fixed typo in `example2.ps1` ("fron json" → "from json")

## Compatibility

* Fully compatible with PowerShell 5.1+ (Windows PowerShell)
* Fully compatible with PowerShell 7+ (PowerShell Core)
* Targets netstandard2.0 for maximum compatibility
* All existing scripts and configurations continue to work without modifications

* Verified on both Windows PowerShell 5.1 and PowerShell 7+
